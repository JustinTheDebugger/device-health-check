How it works

Run the appropriate collector on each laptop, then import its generated JSON file here. Multiple check-ins for the same device are grouped by serial number (or hostname if missing); the latest reading appears on the card. Enter purchase dates manually when available. Sign in once to retrieve the latest NeonDB reports automatically when opening the dashboard. Refresh data on demand. Use Export data to download the latest Excel or JSON for AI analysis. Upload the resulting management PDF to make it available to dashboard users.

Health ratings are triage guidance, not hardware certifications. Missing readings remain unknown. Do not import reports on shared or untrusted computers because hostnames, serial numbers and process names can be sensitive.
